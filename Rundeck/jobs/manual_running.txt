Rundeck Jobs: Manual curl runs
==============================



HomeLab - AI Host Power
=======================

Project: HomeLab
Job ID: 7d9a3328-c8df-4e31-bbf6-49a6d9ce5a11

Required options: vmname (ai-agent or ai-worker) and action (wake or sleep). Sleep suspends the selected host.

# Set these in your shell before running the curl command.
RUNDECK_URL="${RUNDECK_URL:-http://192.168.0.51:4440}"
RUNDECK_TOKEN="${RUNDECK_TOKEN:?Set RUNDECK_TOKEN to a Rundeck API token}"
API_VERSION="${API_VERSION:-50}"

curl --fail-with-body --silent --show-error \
  -X POST "$RUNDECK_URL/api/$API_VERSION/job/7d9a3328-c8df-4e31-bbf6-49a6d9ce5a11/run" \
  -H "X-Rundeck-Auth-Token: $RUNDECK_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{"options":{"vmname":"ai-agent","action":"wake"}}'

The response includes the execution ID and execution URL. Save the execution ID to poll status or retrieve logs through the Rundeck execution API.
